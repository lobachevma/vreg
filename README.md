# VReg — учёт видеорегистраторов

Веб-приложение для учёта видеорегистраторов с авторизацией и базой данных PostgreSQL.

## Запуск

1. Скопируйте `.env.example` в `.env` и задайте значения `ADMIN_PASSWORD` и `SECRET_KEY`.
2. Запустите приложение:

```bash
docker compose up -d --build
```

Приложение будет доступно по адресу: http://localhost

## Вход

| Поле   | Значение      |
|--------|---------------|
| Логин  | `admin`       |
| Пароль | значение `ADMIN_PASSWORD` из `.env` |

## Данные регистратора

- Адрес
- Тип здания
- Модель регистратора
- Количество подключенных камер
- IP адрес регистратора
- Логин
- Глубина записи

## Остановка

```bash
docker compose down
```

Данные БД сохраняются в Docker volume `postgres_data`.

## Краткое описание функционала
Система позволяет вести учет систем видеонаблюдения в организациях с большим парком техники.
 -Функционал:
- 1.Хранение информации о зданиях организации. Добавлена возможность выбирать тип здания (ДОУ или ШКОЛА)
- 2.Создание пользователей с различным уровнем доступа, возможностью редактировать информацию или только просмотром
 -3.Сводная таблица. Показывает всю основную информацию об устройстве. Клик по строчке открывает карточку устройства. Добавление видеорегистратора в систему происходит нажатием на кнопку "ДОБАВИТЬ" 
 -4.Карточки устройства. Переход на Web интерфейс устройства кликом по IP адресу в карточке устройства.
